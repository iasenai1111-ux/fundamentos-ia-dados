📎 Prompt seguro: gerar dados fictícios

Você é um analista de dados de uma construtora. Crie uma tabela FICTÍCIA com 30 linhas para eu testar uma planilha.
Contexto: colunas Matricula (F001 a F010), Nome (nomes inventados), Setor (Elétrica, Hidráulica, Carpintaria, Canteiro, Drywall, Manutenção), Data (dias úteis de outubro de 2026), Minutos_atraso (0 a 90), Horas_extras (0 a 4), Salario_hora (24 a 32).
Intenção: testar um relatório de atrasos e horas extras por setor, sem usar dados reais.
Formato: tabela que eu possa copiar para o Google Planilhas, sem explicações.
